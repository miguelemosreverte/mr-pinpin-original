The Method, in Order

  1. Generate and record three four-by-four directional sheets.
  2. Inspect true transparency, grid bounds, headings and gait phases.
  3. Use the appropriate rendered heading while moving along the path network.
  4. Test map gestures separately from book preview and story opening.

Navigation Policy

Panning, pinching and map taps do not open stories.

A book icon appears only for a clearly focused available destination. Tap it to preview the opening image, then tap that image to read.

Progress changes only when the story is opened. PinPin follows the nearest reachable path without crossing the lake.

Review

Review the gestures, white route dashes, directional animation and localized story previews before publication.

Generated headings are requested 30-degree steps, not angles measured from a 3D model. Asset reviews document deviations. Recorded timing windows include a short orchestration interval before each tool handoff, not just image-tool execution; they are not compute or billing measurements. Desktop/mobile layouts and emulated touch gestures passed in Chrome; physical Safari devices remain untested.
