The Method, in Order

  1. Map all source text to sixteen reading scenes and an eleven-page print edition; reserve separate pages for the empty leaf window and the final face reveal.
  2. Prepare seven new landscape camera directions from clean location plates: leaf level, canopy-up, elder portrait, overhead, visitor portrait, hilltop-up and sunset leaf window. Save prompts before tool calls.
  3. Generate each clean environment, register PNG plus adjacent Markdown/JSON immediately, and inspect it before using it as another reference.
  4. Render the first complete two-character scene as the shared cast reference, then place each scene's entire visible cast together directly on its clean landscape. No colored-limb blocking pass.
  5. Check image scale, direction, identity, face quality, attachment of forelegs/hindlegs, shadows and source timing. Log any rejected attempt rather than overwriting it.
  6. Integrate all text and images, preserve chapter/language query parameters, verify full-width native mobile scrolling and deliberately composed PDF pages, and publish the completed chapter.

What Carries Forward from Chapter 1

Miguel's successful camera directions specified physical travel and relationships: the lake below the path, two retreats of 50 metres, underwater views looking up, and a wet return to the surface. This pass reuses that spatial approach, with deliberate foreground parallax and a reverse view.

The colored-leg blocking experiment did not reliably preserve facial quality or body posture. It is not part of this pass. Future character renders should begin from the clean landscape, place the whole cast together, and receive a separate visual check of faces, scale, gaze and each fore/hind limb attachment.

Repeated edits appeared to brighten highlights; the cause remains unverified. Short reference chains reduce repeated processing but do not guarantee identical exposure. The later rabbit corrections also show that a convincing image can still contain anatomy errors. Prompt compliance must be inspected, not assumed.

The Completed Adaptation

The whole chapter is adapted, including the elder's conversation, the promise of tomorrow and the sunset closing. The last two pages add a silent, playful discovery without changing the plot.
