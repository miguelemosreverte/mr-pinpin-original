# Illustrated chapter work

For a new chapter or a substantial illustration revision, start with [production/CHAPTER-PRODUCTION.md](production/CHAPTER-PRODUCTION.md). It defines the reusable source, character, environment, camera, object-state and review workflow. The chapter's files are the handoff; do not rely on conversation memory.

Read the relevant chapter bible, shot plan, selected manifest and REPORT before changing images. If no pack exists, use `production/chapter-template/`. Inspect and internally review character/scale references and location layouts before narrative renders. Design an interior before using it; do not add unused interiors as ceremony. These are illustrated continuity references, not a calibrated 3D model.

Use the imagegen skill and built-in image tool for raster creation/edits. Keep exact prompts/references/timestamps, hashes and actual visual reviews next to versioned PNGs. Preserve existing approved images and previous attempts. A prompt is not evidence that an output obeyed it; check visible anatomy, actions, geography, camera axes and changing props.

Develop action, reaction and transitions without a fixed image quota. Separate source content from adaptation additions and future promises. Internal production checks do not require repeated permission questions; follow the user's authorized scope through to a complete reviewable result. Keep unfinished or unapproved proposals clearly identified and preserve official editions until the authorized publication step.
