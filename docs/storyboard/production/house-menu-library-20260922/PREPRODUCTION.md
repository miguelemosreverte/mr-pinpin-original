# House entrance and chapter library

The root URL opens the family's room. Its green front door leads to the existing forest atlas; its oak bookcase leads to the PDF chapter library. Both objects have subtle white contours and golden hover/focus feedback, with keyboard and touch equivalents.

The room uses the approved Papa-arrival kitchen as its architecture and style reference. A new camera sees the front door on the left and a reading-nook bookcase on the right. The library is a closer frontal view of that same bookcase. Empty shelf spaces receive the actual approved portrait chapter covers in HTML; generated lettering or fabricated covers are not used as chapter choices.

Preproduction invariants: rounded green door, single brass knob, coherent outward opening; honey-oak wood and cream plaster; eight spokes if a cottage window is visible; three broad cabinet shelves; warm readable animated-feature style; no characters obscuring navigation. Interaction contours share the image's coordinate system. Mobile must retain both navigation targets and aligned shelves.

Nine completed routes receive PDFs in EN, RU and ES, excluding the duplicate continuous compilation. The earlier Elder adaptation remains clearly identified. Existing book content and images are preserved. PDF generation, artwork provenance, and release verification have separate reports in this directory.

Interaction reference: https://github.com/miguelemosreverte/ui-experiment. Implementation uses the object's hover/click concept independently; no unlicensed external code or artwork is copied.
