# C: one-pass cubemap atlas preview

Preview route: http://127.0.0.1:8789/?view=cubemap-unified&lang=ru. Comparison route, maintained by the independent review lane: http://127.0.0.1:8789/room-compare.html?lang=ru&candidate=unified. Default expanded room and A/B renderers remain unchanged.

C samples one texture containing six true 90-degree square faces: top front/right/back, bottom left/up/down. The fragment shader transforms the existing perspective camera ray into world coordinates, selects the dominant cube axis, and maps it into that face's original orientation. Texture coordinates are clamped half an actual texture texel inside each tile boundary so linear filtering cannot bleed from adjacent atlas cells. There is no overscan or broad face blending. Actual atlas dimensions are decoded and validated as six square tiles.

New modules: docs/home-unified-config.js and docs/home-unified-gl.js. Small mode dispatch changes in home-panorama.js plus pause/visibility support in home-camera.js, home-depth.js, home.css and index.html. The existing mouse/touch drag, anchored pinch/wheel zoom, yaw wrap, pitch/FOV limits, native projected links, keyboard reveal/Enter, fixed language flags, same-origin comparison messages and expanded-room fallback are reused. Read-only panoramaView.snapshot exposes view cubemap-unified, asset, decoded dimensions, and six face descriptors with atlas tile coordinates; project(uv) retains the common spherical hotspot contract.

The renderer uses one texture unit, no dependency and no continuous idle drawing. It preserves the existing 1.5 device-pixel-ratio and 2MP render caps. Missing/invalid atlas, unavailable WebGL, context loss and reduced motion use the expanded-room fallback.

Gray guide smoke passed using the exact 3072×2048 atlas via browser request substitution: six faces loaded, expected orientation at front/right/back/left/up/down, continuous front-right stove/corner, zero JavaScript errors, keyboard reveal and Enter opened the Russian library. Evidence is in gray-smoke/result.json and adjacent captures. The gray atlas itself is not selected final artwork.

Selected C artwork is room-unified-cubemap-v2.webp, 1536×1024 with 512-square tiles. This is the whole-atlas workflow: all six faces stylized together, followed by a whole-map correction. It is not assembled from six independent styled generations. V2 removes v1's grid divider lines; doorway and bookcase polygons were calibrated directly to the actual front/right tile pixels, with edge subdivision before spherical projection. The source still has an extra cupboard and geometric discontinuities at some cube edges. Those are visible art limitations; the single-texture sampler does not hide them with overlap blending. C remains a review experiment alongside unchanged A and B, with the normal expanded menu as default. No production switch, Git operation or publication performed.
