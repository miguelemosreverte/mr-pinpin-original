## Production change

The user is right that pretty portraits alone do not establish interaction. The new plan uses explicit paired question/answer views and named gaze targets. Shared attention is reserved for a genuinely visible object. Re-establish the pair and environment after changing mural stations. Every generated dialogue frame will be checked for actual face/pupil direction before selection; a wrong gaze is a render defect to edit, not a reason to rewrite a question into unrelated narration.
