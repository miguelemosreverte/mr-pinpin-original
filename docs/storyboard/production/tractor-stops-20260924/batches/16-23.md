# Restoration batch 16–23: halted after seven calls

Seven built-in image_gen edits executed for stops16–22 using the pilot restore-prompt.txt literally, with each exact source frame as sole input. Sources and returned masters were inspected. Each output is1672×941; exact PNG data-URL bytes were decoded to mini SSD and hashed. Per-stop restore-generation.json records input/output hashes, dimensions, actual call count and transport.

Stop23 was not submitted. No panorama generation or deterministic guides were run in this lane. The coordinator halted further model calls after user feedback that regenerated style/materials were inferior to the original video frame. These are retained candidates, not accepted replacements or ready tour stops.

The seven outputs reduce motion blur and preserve broad viewpoint, but synthesize tire tread, foliage, surface and mechanical details. They do not preserve original pixels. This distinction is material to the user's updated requirement for1:1 source preservation.

Selected future direction is a ray-projected exact original frame in its authored perspective rectangle, with generated periphery separately identified and its perimeter inspected. No such renderer change was made in this batch.
